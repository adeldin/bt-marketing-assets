# Balloon & Tusk — Marketing Assets

Brand-locked, AI-generated imagery for social posts. Served via raw.githubusercontent.com
as stable public URLs (Loomly-compatible: no signing, no expiry).

- `images/` — post imagery, kebab-case names, numbered variants
- Indexed in the Notion **Media Library** database (Image URL column points here)
- Generated per the Brand & Voice Guide visual rules: warm ivory (#F7F4EF), navy (#2C3A44),
  gold (#BFA46F), soft window light, no people, no text-in-image, no logos

URL pattern: `https://raw.githubusercontent.com/adeldin/bt-marketing-assets/main/images/<name>.png`
